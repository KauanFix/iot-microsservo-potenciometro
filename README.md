## Enunciado: Vamos ligar o LED!

O projeto vai utilizar um potenciometro como entrada para controlar um microsservo, o giro do potenciometro será copiado pelo microsservo

- O Arduino lê o estado do potenciometro pelo **pino A0**
- Controla o Microsservo pelo **pino 9**

## Materiais necessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Cabo USB |
| 1 | Protoboard |
| 1 | Potenciometro |
| 1 | Microsservo |
| — | Fios de jumper macho-macho |
